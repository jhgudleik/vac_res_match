
## 1. Описание задачи и методологии

### 1.1 Постановка задачи

Имеется база из **30 резюме** (CV 1 – CV 30) и **5 вакансий** (V1 – V5). Два независимых аннотатора оценили каждую из 150 пар «резюме–вакансия», присвоив ранг от 1 (наилучшее соответствие) до 5 (наихудшее). Задача — построить профиль «среднего аннотатора», который можно использовать как целевую переменную для обучения модели автоматического ранжирования.

### 1.2 Порядок расчетов

Код ноутбука выполняет следующие операции:

1. **Загрузка данных.** Матрицы оценок обоих аннотаторов (30 строк × 5 столбцов каждая) задаются в коде как списки списков и преобразуются в DataFrame.

2. **Вычисление трёх матриц 30×5:**
   - **Средний ранг** = (Ранг_А1 + Ранг_А2) / 2 — основная целевая переменная.
   - **Индекс согласованности** = |Ранг_А1 − Ранг_А2| — мера надёжности среднего ранга (от 0 до 4).
   - **Вес выборки** = 1 − |Ранг_А1 − Ранг_А2| / 4 — нормированный вес для функции потерь модели (от 0.0 до 1.0).

3. **Формирование таблицы профилей** в «длинном» формате (150 строк), где каждая строка — одна пара «вакансия–резюме» с полным набором характеристик, включая текстовую интерпретацию согласованности.

4. **Расчёт метрик межаннотаторского согласия:**
   - Альфа Криппендорфа (α) — по четырём типам шкал: номинальная, ординальная, интервальная, шкала отношений.
   - Корреляция Спирмена (ρ) — по каждой вакансии и общая.
   - Тау Кендалла (τ) — по каждой вакансии.
   - Каппа Коэна (κ) — без весов, с линейными и квадратичными весами.

5. **Визуализация:** четыре графика — heatmap средних рангов, heatmap согласованности, scatter-диаграмма профиля, столбчатая диаграмма метрик по вакансиям.

6. **Сохранение результатов** в файл `average_annotator_profile.xlsx` с пятью листами.

## 2. Анализ листа «Профиль»

### 2.1 Структура

Лист содержит 150 строк — по одной на каждую пару «вакансия–резюме». Столбцы: Вакансия, Резюме, Ранг А1, Ранг А2, Средний ранг, Индекс согласованности, Вес выборки, Интерпретация.

### 2.2 Распределение интерпретаций

Код классифицирует каждую пару по величине расхождения между аннотаторами:

| Интерпретация | Условие | Количество | Доля | Вес выборки |
|---|---|---|---|---|
| **Полное согласие** | Δ = 0 | 46 | 30.7% | 1.00 |
| **Незначительное расхождение** | Δ = 1 | 46 | 30.7% | 0.75 |
| **Существенное расхождение** | Δ = 2 или 3 | 50 | 33.3% | 0.50 или 0.25 |
| **Полное несогласие** | Δ = 4 | 8 | 5.3% | 0.00 |

**Интерпретация:** Надёжные оценки (Δ ≤ 1) составляют 61.4% данных. Это те пары, где аннотаторы расходятся не более чем на 1 балл, и их среднему рангу можно доверять. Оставшиеся 38.6% содержат существенную неопределённость: средний ранг маскирует разногласие. Наиболее проблемны 8 пар с полным несогласием (Δ = 4), где один аннотатор поставил 1, а другой 5 — их средний ранг (всегда = 3.0) фактически бессмысленен.

Все они получают средний ранг 3.0, но при этом один аннотатор считает резюме идеальным, а другой — абсолютно неподходящим. При обучении модели этим парам присваивается вес 0.00, то есть они полностью исключаются из функции потерь.

Наиболее надёжные оценки — когда оба аннотатора поставили одинаковый ранг. Среди таких пар выделяются «безусловно лучшие» (оба поставили 1):

Всего 5 пар из 150 получили наивысший статус «безусловно подходящее резюме». Для вакансий V3 и V5 таких пар нет — аннотаторы не смогли единодушно определить ни одного идеального кандидата.

## 3. Анализ листа «Средние ранги»

### 3.1 Структура

Матрица 30×5: строки — резюме, столбцы — вакансии, значения — средний ранг от 1.0 до 5.0 с шагом 0.5 (9 уникальных значений).

### 3.2 Анализ по вакансиям

**Вакансия V1** — наиболее «дифференцированная». Средние ранги распределены от 1.0 (CV 24, CV 25) до 5.0 (CV 29). Широкий спектр значений в верхней части рейтинга (семь резюме с рангом 1.5) говорит о том, что для V1 существует много потенциально подходящих кандидатов, но лишь два из них — бесспорные лидеры.

**Вакансия V2** — хороший разброс. Единственный бесспорный лидер CV 29 (ранг 1.0), далее плотная группа из пяти резюме с рангом 1.5 (CV 16, CV 17, CV 10, CV 22, CV 30). Характерно, что CV 29, получивший ранг 1.0 для V2, одновременно имеет ранг 5.0 для V1 — это узкоспециализированное резюме.

**Вакансия V3** — наиболее «ровная». Нет ни одного резюме с рангом 1.0, минимальный средний ранг = 1.5, и 12 из 30 резюме сосредоточены в ранге 2.5. Это означает, что многие резюме «средне подходят», но выделить однозначного лидера невозможно.

**Вакансия V4** — имеет два бесспорных лидера (CV 8 и CV 9 с рангом 1.0), но далее сразу идёт провал: следующий ближайший ранг — 2.5 (9 резюме). Разрыв между «идеальными» и «посредственными» кандидатами здесь максимальный.

**Вакансия V5** — аномально бедная на подходящие резюме. Нет ни одного резюме с рангом 1.0 или 1.5, минимальный средний ранг = 2.5 (только CV 18), а 13 из 30 резюме получили ранг 5.0. Это говорит о том, что в базе практически нет подходящих кандидатов для данной вакансии.

### 3.3 Анализ по резюме

**CV 29** — самое «контрастное» резюме: ранг 5.0 для V1, ранг 1.0 для V2, ранг 2.0 для V3, ранг 4.0 для V4, ранг 3.0 для V5. Это узкий специалист, идеально подходящий для одной конкретной вакансии.

**CV 8** — наиболее «стабильно оценённое»: индекс согласованности = 0 для всех пяти вакансий (оба аннотатора всегда совпали). Средние ранги: V1=2, V2=4, V3=3, V4=1, V5=5. Аннотаторы полностью единодушны: CV 8 идеально подходит для V4 и совершенно не подходит для V5.

**CV 5** — одно из наиболее «спорных»: индекс согласованности = 4 для V1 и V2, = 0 для V5. Аннотаторы радикально расходятся в оценке этого резюме для некоторых вакансий, но при этом полностью согласны для других.

## 4. Анализ листа «Индекс согласованности»

### 4.1 Структура

Матрица 30×5: значения — абсолютная разница рангов |А1 − А2|, от 0 до 4.

### 4.2 Ключевые наблюдения

**Резюме с идеальной согласованностью (все нули):** только **CV 8** и **CV 29** имеют Δ = 0 по всем пяти вакансиям. Это означает, что аннотаторы оценивают эти резюме совершенно одинаково, вне зависимости от вакансии. Именно такие пары являются наиболее ценными для обучения модели.

**Резюме с максимальными разногласиями:** CV 3 (Δ = 4 для V1 и V5), CV 5 (Δ = 4 для V1 и V2), CV 27 (Δ = 4 для V5). Эти резюме вызывают полярные оценки — один аннотатор видит в них идеальное соответствие, другой — полное несоответствие.

**По вакансиям:**
- V3 — наиболее согласованная вакансия: среднее Δ = 1.03, 77% пар с Δ ≤ 1.
- V4 — наименее согласованная: среднее Δ = 1.60, только 53% пар с Δ ≤ 1. Особенно характерен кластер из 8 резюме (CV 12–17, CV 19, CV 22–23, CV 27) с Δ = 3 — это резюме, по которым аннотатор 1 ставит ранг 4–5, а аннотатор 2 — ранг 1–2.

## 5. Анализ листа «Веса выборки»

### 5.1 Структура

Матрица 30×5: значения — нормированный вес от 0.00 до 1.00, рассчитанный как 1 − |Δ| / 4.

### 5.2 Смысл весов

Вес определяет вклад каждой пары в функцию потерь при обучении модели:

| Вес | Значение Δ | Смысл | Доля записей |
|---|---|---|---|
| **1.00** | 0 | Полностью учитывается | 30.7% |
| **0.75** | 1 | Учитывается на 3/4 | 30.7% |
| **0.50** | 2 | Учитывается наполовину | 18.0% |
| **0.25** | 3 | Учитывается на 1/4 | 15.3% |
| **0.00** | 4 | Полностью исключается | 5.3% |

### 5.3 Практическое применение

**Суммарный «эффективный» объём выборки:** если просуммировать все веса, получим ~95.5 «эффективных» наблюдений из 150 номинальных. Это значит, что с точки зрения информативности данные эквивалентны примерно 96 полностью согласованным оценкам — потеря около 36% информации из-за несогласованности аннотаторов.

**CV 8** — единственное резюме с весом 1.00 по всем пяти вакансиям. Это «золотой стандарт» — модель должна в первую очередь научиться правильно ранжировать именно его.

**Нулевые веса** (8 пар) означают, что эти наблюдения не должны участвовать в обучении. Если модель предскажет для них любой ранг — это не будет ни ошибкой, ни достижением, потому что «правильного» ранга для них не существует.

## 6. Анализ листа «Метрики»

### 6.1 Альфа Криппендорфа

| Вакансия | α (ординальная) | Интерпретация |
|---|---|---|
| V1 | 0.4497 | Ненадёжное |
| V2 | 0.4736 | Ненадёжное |
| V3 | 0.4543 | Ненадёжное |
| V4 | 0.4765 | Ненадёжное |
| V5 | 0.5149 | Ненадёжное |
| **Общая** | **0.5942** | **Ненадёжное** |

Альфа Криппендорфа учитывает случайное совпадение оценок. Поскольку оба аннотатора используют шкалу из 5 рангов и раскладывают ровно по 6 резюме на каждый ранг, вероятность случайного совпадения составляет 20%. Значение α = 0.59 означает, что согласие аннотаторов лишь на 59% лучше случайного — это значительно ниже порога надёжности (0.667) и далеко от порога хорошего согласия (0.80).

Общая α (0.5942) оказывается выше, чем α по каждой отдельной вакансии (0.45–0.51). Это объясняется тем, что при объединении всех 150 пар появляется «структурный» компонент согласия: оба аннотатора в среднем ставят более низкие ранги для V4 и V5, чем для V1–V3, и эта общая тенденция увеличивает α. Однако внутри каждой вакансии (при фиксированном распределении рангов) согласие остаётся крайне слабым.

### 6.2 Корреляция Спирмена

| Вакансия | ρ | p-value | Значимость |
|---|---|---|---|
| V1 | −0.0766 | 0.6876 | Не значимо |
| V2 | +0.1041 | 0.5840 | Не значимо |
| V3 | −0.1168 | 0.5387 | Не значимо |
| V4 | −0.0207 | 0.9137 | Не значимо |
| V5 | +0.0602 | 0.7519 | Не значимо |
| **Общая** | **+0.1858** | **0.0228** | **Значимо (p < 0.05)** |

Корреляция Спирмена показывает, насколько аннотаторы одинаково упорядочивают резюме. Значения ρ по отдельным вакансиям колеблются около нуля (от −0.12 до +0.10) и ни одно из них не является статистически значимым. Это означает, что для каждой конкретной вакансии аннотаторы ранжируют резюме фактически независимо друг от друга.

Общая корреляция (ρ = 0.19, p = 0.023) формально значима, но по величине эффекта крайне мала. Её статистическая значимость объясняется большим размером выборки (150 пар) и структурным эффектом: оба аннотатора согласны, что, например, для V5 большинство резюме не подходит (много рангов 5), а для V1 — подходит (много рангов 1–2). Это общее согласие на уровне вакансий, а не на уровне конкретных резюме.

### 6.3 Каппа Коэна

| Тип весов | κ | Интерпретация (шкала Лэндиса–Коха) |
|---|---|---|
| Без весов | 0.1333 | Слабое |
| Линейные | 0.1632 | Слабое |
| Квадратичные | 0.1864 | Слабое |

Каппа Коэна подтверждает выводы остальных метрик: согласие между аннотаторами слабое. Линейные веса (κ = 0.16) немного выше невзвешенной каппы (0.13), что означает: когда аннотаторы не совпадают, они чаще расходятся на 1–2 балла, чем на 3–4. Однако даже с учётом этой «частичной» близости оценок уровень согласия остаётся в зоне «слабого».

### 6.4 Дополнительные показатели по вакансиям

| Вакансия | Ср. Δ | Полное согласие (Δ=0) | Близкое (Δ≤1) |
|---|---|---|---|
| V1 | 1.53 | 17% | 57% |
| V2 | 1.37 | 27% | 57% |
| V3 | 1.03 | 30% | 77% |
| V4 | 1.60 | 30% | 53% |
| V5 | 1.17 | 50% | 63% |

**V5** имеет наивысший процент полного согласия (50%), но это обманчивый показатель: аннотаторы согласны в основном на ранге 5 (13 резюме из 15 с Δ=0 получили ранг 5.0). Согласие «это не подходит» — тривиальное и малоинформативное для модели.

**V3** — лучший баланс: самое низкое среднее Δ (1.03) и наивысшая доля близких оценок (77%). Это единственная вакансия, где более трёх четвертей оценок отличаются не более чем на 1 балл. При обучении модели данные по V3 будут наиболее надёжными.

**V4** — наихудшая согласованность: среднее Δ = 1.60, только 53% близких оценок. Характерен кластер из 8 резюме (CV 12–17, CV 19) с Δ = 3, где аннотатор 1 систематически ставит ранг 4, а аннотатор 2 — ранг 1. Это может указывать на принципиально разное понимание требований этой вакансии.

## 7. Интерпретация результатов

### 7.1 Первоначальные данные

Аннотаторы **идеально откалиброваны по распределению** (каждый ставит ровно 30 оценок каждого ранга из 150), но **практически не согласованы по содержанию** (корреляция ≈ 0 по каждой вакансии). Они используют одинаковую шкалу, но применяют к конкретным резюме совершенно разные критерии.

### 7.2 Надёжность среднего ранга

Средний ранг является приемлемой целевой переменной для 61.3% данных (Δ ≤ 1). Для остальных 38.7% средний ранг содержит существенную неопределённость, а для 5.3% (Δ = 4) — бессмысленен. Двумерный профиль (средний ранг + индекс согласованности) позволяет учесть эту неопределенность при обучении через весовую функцию.
