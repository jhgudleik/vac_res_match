Список файлов с описанием (зона ответственности Демича К.):

1. vectorization/heuristic_summary.py  модуль содержит функцию извлечния саммари по эвристикам (от Бориса)

2. vectorization/ngramm.py модуль содержит функцию токенизации по 3-граммам (от Александра)

3. vectorization/scills.py модуль содержит функцию извлечения навыков (от Анны)

4. vectorization/summary_generator.py модуль содержит функцию извлечния саммари (от Бориса), адаптированную под использование моделей GEMINI или доступных на OPENROUTER

5. vectorization/vac_scill_vectorizer_2.ipynb нотбук осуществляет сравнение по косинусному расстоянию вакансий с резюме по извлечененным навыкам

6. vectorization/vac_sum_vectorizer_2.ipynb нотбук осуществляет сравнение по косинусному расстоянию вакансий с резюме по извлеченному с помощью моделей саммари

7. /vac_sum_vectorizer_heu.ipynb нотбук осуществляет сравнение по косинусному расстоянию вакансий с резюме по извлеченному по эвристикам саммари

8. vectorization/vac_vectorizer.ipynb нотбук осуществляет сравнение по косинусному расстоянию полного текста вакансий с резюме на модели nomic-ai/nomic-embed-text-v1.5 (представленна авторами исследования)

9. vectorization/vac_vectorizer_2.ipynb нотбук осуществляет сравнение по косинусному расстоянию полного текста вакансий с резюме на модели all-MiniLM-L6-v2

10. vectorization/vac_vectorizer_2_nramm.ipynb нотбук осуществляет сравнение по косинусному расстоянию полного текста вакансий с резюме на модели all-MiniLM-L6-v2 с внешней токенизацией по 3-граммам

11. vectorization/vectorizer.ipynb нотбук содержит код наполнения основной векторной базы с резюме, используемой в n8n

12. vectorizer_best_scill.ipynb vectorization/vectorizer.ipynb нотбук содержит код наполнения альтернативной векторной базы с резюме, используемой в n8n, с векторизацией навыков
